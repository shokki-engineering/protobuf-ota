## Resource names

Every hotel is addressed by a name that alternates collection and identifier,
per [AIP-122](https://aip.dev/122):

```mermaid
packet
0-5: "hotels"
6: "/"
7-13: "{hotel}"
```

The last segment is OTA's `@HotelCode`, verbatim -- OTA codes are case-sensitive,
so it is not lower-cased ([decisions](../../../../docs/decisions.md)).
